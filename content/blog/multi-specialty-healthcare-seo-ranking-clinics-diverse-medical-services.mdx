## Healthcare Schema Markup Implementation

MedicalWebPage + MedicalSpecialty schema boosts rich results, knowledge graph.

### Clinic Template:
````
&lt;script type="application/ld+json">
{  
"@context": "https://schema.org",
 "@type": "MedicalClinic",
 "name": "[Clinic]: Orthopedics",
 "medicalSpecialty": "OrthopedicSurgery",
 "address": {...}
}
&lt;/script>
````

### Physician Template:
````
{  
"@type": "Physician",
 "name": "Dr. Jane Doe",
 "medicalSpecialty": "Cardiovascular",
 "affiliation": {"@type": "MedicalOrganization", "name": "[Clinic]"}
}  
````

**Validate:** Google Rich Results Test. Enumerations from Schema.org.

#### External Reference: [**Schema.org MedicalSpecialty**](https://schema.org/MedicalSpecialty).
