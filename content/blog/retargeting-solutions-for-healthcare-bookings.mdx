## HIPAA-Compliant Setup for Retargeting Campaigns

Healthcare retargeting demands privacy-first tools since Google and Meta won't sign BAAs for PHI. Freshpaint acts as a gateway, redacting PHI before syncing audiences to ad platforms.  

Use Meta Conversions API for server-side tracking, stripping sensitive data like IP addresses. For patients retargeting ads, avoid condition-specific pages; focus on general behaviors.

### Actionable Tips for Compliance:

- Implement server-side Google Tag Manager (sGTM) with anonymizers.  
- Sign BAAs with CDPs like Freshpaint.  
- Audit for rogue pixels using tools like Ours Privacy.  
- Disable advanced matching in Meta to prevent PHI leaks.
